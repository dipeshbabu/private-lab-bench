# Controlled local scoring fixture

`model.json` is a frozen illustrative linear solubility formula with molecular weight (`g/mol`) and LogP (`dimensionless`) features. Its coefficients are invented; it is not fitted or validated for scientific use. `inputs.csv` contains 24 synthetic observations (CC0). Model/code are MIT licensed.

See [the trusted scoring walkthrough](../../docs/trusted_scoring.md) for the reviewed manifest, unit declarations, local predictions, optional evaluation, and trust limits. No executable model or downloaded dependency is stored here.

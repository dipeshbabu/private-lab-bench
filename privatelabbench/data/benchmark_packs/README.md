# PrivateLabBench Community Benchmark Packs

This directory contains small, versioned, self-contained evaluation examples using `benchmark-pack/v1`.

The included data are synthetic and released as CC0-1.0 for software/evaluation testing. They are not intended as scientific reference datasets or state-of-the-art leaderboards.

See [`docs/benchmark_packs.md`](../docs/benchmark_packs.md) for the format, usage, and contribution rules.

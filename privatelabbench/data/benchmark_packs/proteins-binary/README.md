# Protein Binary Classification Pack

Stable ref: `community-proteins-binary@1.0.0`

A synthetic protein-sequence classification prediction table. It demonstrates that scientific-domain packs can use the generic prediction protocol: sequences and family labels are metadata; no protein model or database is required.

**Provenance:** every sequence, target, prediction, and family assignment in this pack was fabricated for software testing and is not derived from UniProt, PDB, or another biological dataset. Released under CC0-1.0.

```bash
plb run-pack community-proteins-binary@1.0.0
```
